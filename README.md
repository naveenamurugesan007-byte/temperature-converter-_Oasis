🌡 Temperature Converter

A modern and responsive temperature converter web application built using HTML, CSS, and JavaScript. This project allows users to easily convert temperatures between Celsius, Fahrenheit, and Kelvin with a clean UI and dark mode support.

✨ Features

🌗 Dark Mode Toggle – Switch between light and dark themes
🌡 Multi-Unit Conversion – Convert between Celsius, Fahrenheit, and Kelvin
⚡ Instant Results – Displays output immediately
📱 Responsive Design – Works on mobile and desktop
🎨 Smooth UI – Clean design with hover and transition effects

🛠️ Technologies Used

HTML5
CSS3
JavaScript

🚀 How to Run the Project

Clone the repository

Open the folder

Run the project:
Double-click index.html
OR
Open with any browser

🎯 Functionality

Enter temperature → Input any numeric value
Select unit → Choose Celsius, Fahrenheit, or Kelvin
Click Convert → Displays converted values instantly
Click 🌙 / ☀️ → Toggle between dark and light mode
